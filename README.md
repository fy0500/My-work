# Mon portfolio de projets géomatique et analyse spatiale

Bienvenue dans ce dépôt, qui regroupe mes travaux, expérimentations et projets en géomatique, télédétection, traitement d’images satellites, analyse de données spatiales et science des données.

Ce repository illustre ma progression technique et ma spécialisation dans les domaines suivants :

- Télédétection et traitement d’images Sentinel
- Analyse spatiale et cartographie
- Classification d’images / détection d’objets
- Google Earth Engine (GEE)
- OpenEO
- Automatisation de tâches de collecte et de traitement de données
- Python pour la géomatique et l’analyse de données

## Contenu du dépôt

- `Automatisation du téléchargement des données sentinel2` : scripts et notebooks pour automatiser la récupération de données Sentinel-2.
- `DetectionJardins` : travaux liés à la détection de jardins / objets sur images.
- `Javascript GEE classification` : projets de classification avec JavaScript dans Google Earth Engine.
- `OPENEO` : expérimentations avec la plateforme OpenEO pour le traitement de données d’observation de la Terre.
- `Python` : scripts et analyses Python pour des traitements géospatiaux et de données.
- `Sismcité` : projets ou analyses liés à la sismologie / données urbaines / environnement.

## Objectif du projet

Ce dépôt sert de portfolio personnel. Il me permet de :

- conserver et organiser mes projets de recherche et de développement ;
- démontrer ma progression en géomatique ;
- expérimenter de nouvelles méthodes d’analyse spatiale ;
- partager mes travaux et mes compétences de manière claire et structurée.

## Stack technique

Les projets de ce dépôt utilisent principalement :

- Python
- Jupyter Notebook
- GeoPandas
- Rasterio
- NumPy / Pandas
- Matplotlib / Seaborn
- Google Earth Engine
- OpenEO
- Outils de traitement d’images et de géodonnées
